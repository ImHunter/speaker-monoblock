# Глоссарий

| Термин | Значение |
|---|---|
| ЗЯ | Закрытый ящик (акустическое оформление) |
| Qtc, Fc | Добротность и резонансная частота динамика в ящике |
| Баффл-степ | Спад НЧ из-за огибания корпусом; компенсируется Low Shelf в DSP |
| DSP | ADAU1701 на JAB4; настраивается в SigmaStudio |
| PEQ | Параметрический эквалайзер |
| PE | Защитная земля (жёлто-зелёный) |
| FG | Frame Ground — клемма корпуса БП, центр «звезды» заземления |
| ПМЛ | Медная плетёнка, шлейфы заземления |
| НШВИ | Наконечник штыревой (втулочный) изолированный |
| НКИ | Кольцевой наконечник (в силовой части не применяется) |
| НВИ | Наконечник вилочный изолированный (акустические провода) |
| WAGO 221-413 | Рычажная клемма на 3 проводника |
| NTC | Термистор, ограничитель пускового тока |
| MOV | Варистор (10D471K) |
| C14-модуль | Панельный разъём IEC C14 с фильтром и выключателем |
| ASA / FDM | Материал и способ печати держателя клемм |
| Стяжки с площадками | Самоклеящиеся площадки под кабельные стяжки |
| Футорка Permo D5 | Резьбовая вставка в МДФ, вклеивается в сверление Ø5 |
| Stik-o-Seal | Пластилин для герметизации стыков |
| Фоамиран | Вспененный материал для прокладок под динамики и колодки |
