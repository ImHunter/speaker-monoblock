# Глоссарий

> **Добавлено при реорганизации** (в исходнике глоссария нет).

| Термин | Значение |
|---|---|
| ЗЯ | закрытый ящик |
| Qtc, Fc | добротность и резонансная частота динамика в ящике |
| Баффл-степ | спад НЧ из-за огибания корпусом; компенсируется Low Shelf |
| PEQ | параметрический эквалайзер |
| PE | защитная земля (жёлто-зелёный) |
| FG | frame ground, клемма корпуса БП, центр «звезды» заземления |
| ПМЛ | медная плетёнка, шлейфы заземления |
| НШВИ | наконечник штыревой (втулочный) изолированный |
| НКИ | кольцевой наконечник (в силовой части не применяется) |
| НВИ | наконечник вилочный изолированный (акустика) |
| WAGO 221-413 | рычажная клемма на 3 проводника |
| NTC | термистор, ограничитель пускового тока |
| MOV | варистор 10D471K |
| C14-модуль | панельный разъём IEC C14 с фильтром и выключателем |
| ASA / FDM | материал и способ печати держателя клемм |
| Футорка Permo D5 | резьбовая вставка в МДФ, вклеивается в сверление ∅5 |
| Stik-o-Seal | пластилин для герметизации стыков |
| Фоамиран | вспененный материал для прокладок под динамики (в v9 колодок нет) |

## Стороны корпуса

| Термин | Значение |
|---|---|
| **Боковина У** | левая боковина, если смотреть **спереди** (на переднюю панель снаружи); сторона усилителя/JAB4; v9 — X 0…16, v8.0 — X 0…16 |
| **Боковина ВВ** | правая боковина, если смотреть **спереди**; высоковольтная сторона (C14/БП); v9 — X 376…392, v8.0 — X 340…356 |
