# ADR-005: Силовой ввод — модуль C14 + рычажные клеммы WAGO (ревизия 4)

- Статус: accepted
- Источник: v8.0 §4.4, §12

## Решение
Панельный модуль C14 (EMI-фильтр, выключатель, держатель предохранителя T1A) → ASA-держатель с тремя WAGO 221-413 (NTC и MOV «в воздухе») → три одиночных провода ПВ3 0.75 мм² на БП. PE — независимым транзитом от лепестка C14 до FG БП.

## Заменено
Поворотный шарнирный ввод с кабелем ПВС; клеммная колодка Wanjie; кабель ПВС.

## Принципы
Ни одного лишнего соединения; ни одной клеевой точки по МДФ/фольге; все фиксации открываемые; замена любого проводника без затрагивания соседних; без подкладок под держатель.

## Последствия
Единый набор приёмов монтажа в `techniques/`; сервисная матрица в `modules/power-input/service.md`.
