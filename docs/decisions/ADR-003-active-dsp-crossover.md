# ADR-003: Активный DSP-кроссовер на Wondom JAB4

- Статус: accepted
- Источник: v8.0 §1.1, §1.3

## Решение
Усилитель класса D 2.1 на TPA3221 с DSP ADAU1701; кроссовер 2500 Гц, EQ, компенсация баффл-степа и разницы чувствительности — в DSP. Bluetooth 5.0.

## Основания
Программная частота раздела, порядок фильтра и уровни; коррекция АЧХ ЗЯ (subsonic, PEQ); нативный 2.1.

## Отвергнуто
- Пассивный кроссовер — трудоёмкая настройка, негибкость.
- JAB3+ — нет нативного 2.1.
- Аналоговый кроссовер — пайка SMD, негибкость.
