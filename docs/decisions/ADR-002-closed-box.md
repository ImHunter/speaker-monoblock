# ADR-002: Закрытый ящик 5.9 л

- Статус: accepted
- Источник: v8.0 §1.4

## Решение
Закрытый ящик, эффективный объём 5.9 л (геометрия 6.87 л), Qtc ≈ 1.05, Fc ≈ 95 Гц. Нижняя граница −3 дБ: 70–75 Гц без DSP, 60–65 Гц с DSP.

## Основания
Упругий, панчевый бас на малой громкости; компактный корпус; простая настройка.

## Отвергнуто
- Фазоинвертор — громоздкий.
- Толстая кромка 2 мм — удорожание заказа.
- Задняя и верхняя панель из ЛДСП — проблема монтажа разъёмов и регуляторов.

## Последствия
Горб на 95 Гц подавляется PEQ; subsonic HPF 60 Гц; подъём 45 Гц эквалайзером не применяется (риск перегрузки диффузора и клиппинга). См. OQ-006 по уточнению Qtc.
