# ADR-004: Выбор динамиков

- Статус: accepted
- Источник: v8.0 §1.2

## Решение
- НЧ/СЧ: `CMP-wavecor-wf168om01` — бумажный диффузор, натуральная середина, упругий бас в ЗЯ 5.4–5.9 л.
- ВЧ: `CMP-sica-lp53x58-28-n20tw` — шёлковый купол, закрытая задняя камера. Разница чувствительности (~8 дБ) компенсируется в DSP.

## Отвергнуто
Monacor SPH-170 (исчез из продажи), Visaton W 170 S (труднодоступен), Peerless SDS (периодически пропадает), Vifa BC25SC06-04 и Peerless DX25TG59-04 (заменены на Sica по доступности и цене).
