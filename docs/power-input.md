# Силовой ввод (ревизия 4)

Сетевая часть 220–250 В. Числа — [`params.yaml`](../params.yaml), секция `power`. Приёмы — [techniques.md](techniques.md). Корпус — [enclosure.md](enclosure.md), заземление — [shielding.md](shielding.md).

## 1. Состав узла
Панельный модуль C14 `CMP-dl-1dz2kr` (фильтр, выключатель, держатель предохранителя T1A) → ASA-держатель `CMP-holder-wago-asa` с тремя рычажными клеммами `CMP-wago-221-413` и угловым размещением NTC и MOV → три одиночных провода ПВ3 0.75 мм² (L, N, PE) на БП `CMP-meanwell-lrs-100-24`. PE идёт независимым транзитом от лепестка C14 до клеммы FG БП, минуя держатель. Экранирование L/N не применяется (EMI-фильтр в C14); ферриты на сетевой части не используются.

Принципы:
1. Ни одного лишнего соединения в силовой цепи: без муфт, стыков, паек.
2. Ни одной клеевой точки по МДФ и фольговому экрану; силикон допустим только по ASA-держателю, опционально.
3. Все фиксации открываемые; замена любого проводника без затрагивания соседних трасс.
4. Без подкладок под потайной крепёж держателя; посадка жёсткая.

Решение заменило поворотный шарнирный ввод с кабелем ПВС и клеммную колодку Wanjie.

## 2. Схема
```
      NTC, диск +45° вокруг оси выводов,   MOV, диск −45°, без наклона
      наклон тела вверх-наружу
   [1c NTC-1] [2a NTC-2]              [2c MOV-1] [3a MOV-2]
   1b  L от C14 (обход по плоскости     2b  L к БП (подъём по центру
       стенки)                              лицевой грани из канала)
   1a  резерв, рычаг закрыт             3b  N к БП (подъём справа из канала)
                                        3c  N от C14 (вход над якорем)
```
Нумерация: клемма 1 — левая колонка (1a низ → 1c верх), клемма 2 — верхний ряд (2a лево → 2c право), клемма 3 — правая колонка (3a верх → 3c низ).

| Узел | Контакты | Содержимое |
|---|---|---|
| Клемма 1 | 1b, 1c | L до NTC |
| Клемма 2 | 2a, 2b, 2c | L после NTC |
| Клемма 3 | 3a, 3b, 3c | N |

Цепи:
```
L (C14 LOAD L) → 1b → [1c] NTC [2a] → 2b → L БП
N (C14 LOAD N) → 3c → 3b → N БП
MOV: 2c ↔ 3a
PE (лепесток C14) → независимым транзитом → FG БП
```
Инварианты: PE не проходит через держатель; NTC строго последовательно в L после выключателя; MOV между L после NTC и N.

## 3. Размещение
| Элемент | Позиция |
|---|---|
| Модуль C14 | низ фланца 54 мм от дна; штыри L/N/PE смотрят внутрь корпуса вдоль X |
| Держатель | пятно 34<!--p:power.holder_footprint-->×34 мм; верхняя грань 44<!--p:power.holder_top_min-->–46<!--p:power.holder_top_max--> мм, нижняя 10<!--p:power.holder_bottom_min-->–12<!--p:power.holder_bottom_max--> мм; выступ по X 20<!--p:power.holder_protrusion--> мм; при нехватке коридора справа сдвинуть на 3–4 мм к задней стенке |
| Вводы клемм | лицевая плоскость держателя, X ≈ 20 мм, оси вдоль X |
| Клипса №1 | правая стенка, y ≈ 15<!--p:power.clip1_y_min-->–20<!--p:power.clip1_y_max--> мм, правее нижнего угла держателя |
| Клипса №2 | пол, середина прямого участка, ≥15–20 мм от обеих дуг |
| NTC / MOV | перед углами в плоскости вводов, X ≈ 20 мм |

L/N прокладываются по правой стороне отсека, максимально удалённо от сигнальных цепей.

## 4. Крепление NTC и MOV
См. [T-006](techniques.md#t-006-крепление-ntc-и-mov-в-воздухе). Тепловые пороги после прогона: зажимы ≤60–70 °C, ASA-угол ≤40–45 °C.

## 5. Крепление к модулю C14
- Клеммы «мама» 6.3 мм, полностью изолированные, на штырях L/N/PE; двойной обжим по жиле и изоляции, персональная разгрузка изгиба — [T-001](techniques.md#t-001-обжим-клемм-мама-63-мм).
- **Блок для клипс** (`CMP-clip-block-c14`, аксессуар к C14) крепится к корпусу модуля (предпочтительно механически) и фиксирует пучок до точки разгрузки, организуя спуск по правой стороне без провисания.

## 6. Трассы и точки разгрузки
**От C14:** пучок трёх проводов спускается по правой стороне вдоль банки фильтра; пролёт C14 → якорь 35–40 мм без опор. **Клипса №1** — точка разгрузки пучка (трилистник 3×ПВ3 ≈5.6 мм в клипсе 7 мм, [T-004](techniques.md#t-004-монтаж-кабельных-клипс)). Хвосты после якоря: N → 3c (5–10 мм); L → обход по плоскости стенки; PE → вниз по правой кромке.

**К БП:** три одиночных провода: коричневый (L) → 2b, синий (N) → 3b, жёлто-зелёный (PE) транзитом. На полу три провода в трилистник; клипса №2 на прямом участке полупути; PE длиннее L/N на 2–3 см ([T-003](techniques.md#t-003-правила-слабины)). У БП оконцовка НШВИ 0.75×8 ([T-002](techniques.md#t-002-обжим-ншви-и-подключение-к-бп)).

## 7. Порядок сборки
1. Обжать клеммы «мама» на L/N/PE, персональная разгрузка (T-001).
2. Блок для клипс на корпус C14.
3. На свободном держателе: L от C14 → 1b, N от C14 → 3c, L к БП → 2b, N к БП → 3b, выводы NTC → 1c/2a, выводы MOV → 2c/3a; рычаг 1a закрыть (T-006).
4. Прикрутить держатель потайными саморезами с фиксатором резьбы; проверить коридор ≥13 мм справа (T-005).
5. Надеть клеммы «мама» на штыри модуля; пучок в блок для клипс.
6. Клипса №1 на правой стенке.
7. Три провода к БП на пол; клипса №2.
8. НШВИ у БП, вставить в L/N/FG, затянуть 0.4–0.6 Н·м (T-002).
9. Вставить предохранитель T1A.
10. Проверки (раздел 8).
11. Через 24–48 ч подтянуть саморезы держателя.

## 8. Проверки
| Тип | Проверка | Критерий |
|---|---|---|
| Электрическая | PE: лепесток C14 ↔ FG БП | сплошная цепь |
| Электрическая | L: штырь LOAD L ↔ L БП; N: LOAD N ↔ N БП; изоляция | цепь есть; >1 МОм |
| Механическая | рывок трасс; пальцевый тест NTC/MOV; зазоры по T-006 | неподвижны |
| Вибрационная | бас-тест 40–80 Гц | нет дребезга |
| Тепловая | прогон 30–60 мин | зажимы ≤70 °C, ASA ≤45 °C |
| Повторная | подтяжка через 24–48 ч | выполнена |

Первый запуск — [commissioning.md](commissioning.md).

## 9. Сервисная матрица
| Операция | Открывается | Разрушается |
|---|---|---|
| Замена NTC / MOV | два рычага угла | ничего |
| Замена провода от C14 | клипса №1, рычаг, клемма «мама» | только усадка (если выбрана) |
| Замена провода к БП | клипса №2, рычаг, винт БП | ничего |
| Замена PE | клипсы №1 и №2, «мама», винт FG | ничего |
| Снятие держателя | 2 самореза | ничего |

## 10. Запреты
Нарушение требует записи в [project.md](project.md) и подтверждения человека.
1. Стыки, муфты, пайка в силовых цепях.
2. Клей по МДФ/фольге; липучки и скотч в силовом монтаже.
3. Подкладки под держатель.
4. Изгибы выводов ближе 3 мм к корпусу/зеву.
5. Зажим на дугах изгиба.
6. Зазор варистора <4 мм.
7. НШВИ на стороне WAGO; кольцевые наконечники.
8. Термоусадка поверх всего пучка.
9. Включение C14 чаще раза в 30 с.
10. PE через держатель WAGO.
