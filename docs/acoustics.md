# Акустика: закрытый ящик и демпфирование

Числа — [`params.yaml`](../params.yaml), секции `acoustics` и `global`. DSP-коррекция — [dsp.md](dsp.md). Геометрия — [enclosure.md](enclosure.md).

## 1. Динамики
- НЧ/СЧ `CMP-wavecor-wf168om01` (6.5″, 4 Ом, 88 дБ): Fs 39<!--p:acoustics.woofer_fs_hz--> Гц, Qts 0.45<!--p:acoustics.woofer_qts-->, Vas 29.5<!--p:acoustics.woofer_vas_l--> л. Бумажный диффузор, натуральная середина, упругий бас в ЗЯ.
- ВЧ `CMP-sica-lp53x58-28-n20tw` (1″, 8 Ом, 95.8<!--p:acoustics.tweeter_sens_db--> дБ): шёлковый купол, закрытая задняя камера. Разница чувствительности компенсируется в DSP.

## 2. Закрытый ящик
- Эффективный объём 5.9<!--p:global.v_eff_l--> л.
- Qtc ≈ 1.05<!--p:acoustics.qtc-->, Fc ≈ 95<!--p:acoustics.fc_hz--> Гц. Расчёт по Qts·√(1+Vas/Vb) даёт ≈1.10 — OQ-006.
- Нижняя граница −3 дБ: 70–75 Гц без DSP; с DSP 60<!--p:acoustics.f3_with_dsp_min-->–65<!--p:acoustics.f3_with_dsp_max--> Гц (подавление горба на 95 Гц, subsonic 60 Гц).
- Искусственный подъём 45 Гц эквалайзером нецелесообразен (перегрузка диффузора, клиппинг усилителя).
- Прослушивание преимущественно на малой громкости; цель — хороший бас в этом режиме.

## 3. Демпфирующие маты (съёмные)
Синтепон `CMP-synthetic-batting` 100–150 г/м², сложенный до 10–20 мм, в оболочке из спанбонда 60–80 г/м² (`CMP-spunbond`), простёганной по периметру и 2–3 поперечными строчками. По периметру пришита мягкая часть велкро (петли) шириной 20 мм. Ставятся на все поверхности акустического отсека, кроме передней панели.

**Ответные части:** квадратики жёсткой части велкро 20×20 мм точечно на двухкомпонентный эпоксид (малые капли по углам). Количество точек: перегородка 6 (по углам + 2 в центре верх/низ); боковины по 4; верх 4; низ 4.

| Поверхность | Размер Ш×В, мм | Вырезы | Толщина, мм |
|---|---|---|---|
| Перегородка | 322×194 | под колодки: ~100×60 (ТВ-2504 + ТВ-1504), ~60×60 (ТВ-1504 сигнальная); круглые под жгуты при необходимости | 15–20 |
| Левая / правая боковина | 110×194 | нет | 10–15 |
| Верх | 322×110 | нет | 10–15 |
| Низ | 322×110 | нет | 10–15 |

## 4. Изготовление и укладка
1. Синтепон по размеру поверхности минус 5 мм по периметру.
2. Обернуть тканью с припуском 20 мм, прошить по краю, 2–3 поперечные строчки.
3. Пришить петли велкро по периметру с шагом по точкам на корпусе.
4. Крючки велкро клеить на панели до сборки каркаса.
5. Жгуты от колодок к динамикам проложить по дну и зафиксировать стяжками с площадками **до** установки нижнего мата; нижний мат ложится поверх проводов. Вырезы перегородочного мата совпадают с колодками и проходками.
