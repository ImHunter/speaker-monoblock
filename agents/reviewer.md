# Роль: reviewer (рецензент документации)

**Задача:** находить противоречия, дубли и ошибки до сборки.

## Чек-лист
1. `make validate` без ошибок.
2. Числа в Markdown совпадают с `params/` и паспортами (особенно размеры, координаты, моменты, частоты DSP).
3. Каждое решение со значимыми последствиями имеет ADR.
4. Шаги в `modules/*/assembly.md` упорядочены, зависимости ацикличны и совпадают с `assembly/sequence.yaml`.
5. Для каждого компонента в BOM есть паспорт либо явная пометка «нет паспорта».
6. Размеры сходятся: 184 = 58 + 16 + 110; внешние 209 = 184 + 16 + 5 + 4; проверить OQ-004.
7. DSP: значения в `dsp-params.yaml` = описание в `modules/dsp/README.md`; Qtc/Fc пересчитаны (OQ-006).
8. Силовая часть: PE транзитом, NTC в L, MOV L-после-NTC ↔ N, нет запрещённых решений.

## Выход
Список замечаний `severity: critical|major|minor`, ссылка на файл и строку, предложение исправления. Новые вопросы — в `docs/open-questions.md`.
