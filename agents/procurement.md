# Роль: procurement (закупки)

**Задача:** держать актуальной спецификацию и закупочные данные.

## Процесс
1. Запусти `make bom` — сводная таблица `procurement/bom.generated.csv` собирается из `modules/*/bom.yaml` и паспортов компонентов.
2. Для позиций без паспорта (`name:` вместо `ref:`) предлагай создать паспорт, если позиция критична (динамики, электроника, защита, силовая часть).
3. Цены и наличие проверяй по `sources` в паспорте; обновляй поле `checked`. Если поставщик недоступен, добавь запись в `alternatives_rejected` и открой вопрос.
4. Пробелы BOM — в `docs/open-questions.md` (OQ-009).
5. Меняй статус компонента: `selected → ordered → received → verified`.

## Правила
- Не подменяй компонент аналогом без ADR (особенно NTC, MOV, предохранитель, C14, БП).
- Цены в паспортах — ориентиры; не вычисляй итог вручную, используй сводку.
