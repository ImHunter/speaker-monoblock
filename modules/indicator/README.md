# Модуль indicator — светодиодный индикатор на передней панели

Источник: v8.0 §4.11. Не нарушает герметичность акустического отсека.

## Состав
- Световод жёсткий 3 мм (BIVAR PLP2-750 или аналог) в отверстии ∅3 мм в передней панели (МДФ + накладка), заподлицо с накладкой.
- Держатель светодиода 3 мм металлический (Arlight 3CCI) с зажимной гайкой и капроновой втулкой — на пластине ABS 1.5–2 мм, пластина на внутренней стороне панели через футорки D5.
- Светодиод 3 мм с плоской линзой (OPTOSUPPLY OSB5SA3NE4A) — сзади в держатель, линза прижата к торцу световода.

## Подключение
Провода 0.5 мм² (оранжевый LED+, чёрный LED− с биркой) через резистор 2.7 кОм к +24 В от БП. Ножки светодиода и резистор изолируются тонкой термоусадкой. Выводятся через правую проходку перегородки на колодку ТВ-1504 (сигнальную).

## Монтаж
См. [`assembly.md`](assembly.md). Демонтаж: светодиод вынимается из держателя, панель снимается вместе со световодом и держателем, провода остаются в акустическом отсеке.

Закупочные пробелы — OQ-009.
