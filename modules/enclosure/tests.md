# Проверки корпуса

| ID | Проверка | Критерий |
|---|---|---|
| TEST-ENC-01 | Прямоугольность каркаса (диагонали) | расхождение ≤1–2 мм |
| TEST-ENC-02 | Зазор перегородка → плата JAB4 / задняя панель → плата | 12 мм / 44–45 мм |
| TEST-ENC-03 | Герметичность акустического отсека (мягкое надавливание на диффузор, прислушаться к свисту) | нет шипения/подсвистов |
| TEST-ENC-04 | Прижим передней панели | прокладка сжата ~1 мм по периметру |
| TEST-ENC-05 | Бас-тест 40–80 Гц | нет дребезга и призвуков |
