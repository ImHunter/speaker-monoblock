# Модуль power-input — силовой ввод (ревизия 4)

Источник: v8.0 §4.4, §5.1, §7 (шаги 1–2). ADR: [ADR-005](../../docs/decisions/ADR-005-c14-module-wago.md). Параметры: [`params/power.yaml`](../../params/power.yaml).

## Состав узла
Панельный модуль C14 (`CMP-dl-1dz2kr`: фильтр, выключатель, предохранитель T1A) → держатель с тремя WAGO 221-413 (`CMP-holder-wago-asa`) с угловым размещением NTC и MOV → три одиночных провода ПВ3 0.75 мм² (L, N, PE) на блок питания (`CMP-meanwell-lrs-100-24`). PE — независимым транзитом от лепестка C14 до FG БП, минуя держатель.

## Принципы
1. Ни одного лишнего соединения в силовой цепи: без муфт, стыков, паек.
2. Ни одной клеевой точки по МДФ и фольговому экрану; силикон допустим только по ASA-держателю и опционально.
3. Ни одной намертво связанной точки: замена любого проводника без затрагивания соседних трасс.
4. Ни одной подкладки под держатель; посадка жёсткая.

## Размещение
| Элемент | Позиция |
|---|---|
| Модуль C14 | низ фланца 54 мм от дна; штыри L/N/PE смотрят внутрь вдоль X |
| Держатель | пятно 34×34 мм; верх 44–46 мм, низ 10–12 мм; выступ по X 20 мм; при нехватке коридора справа сдвинуть на 3–4 мм к задней стенке |
| Вводы клемм | лицевая плоскость держателя, X ≈ 20 мм, оси вдоль X |
| Клипса №1 | правая стенка, y ≈ 15–20 мм, правее нижнего угла держателя |
| Клипса №2 | пол, середина прямого участка, ≥15–20 мм от обеих дуг |
| NTC / MOV | перед углами в плоскости вводов, X ≈ 20 мм |

Числа продублированы из `params/power.yaml` для чтения; при расхождении верен YAML.

## Схема
Машиночитаемо: [`netlist.yaml`](netlist.yaml).

```
      NTC, диск +45° вокруг оси выводов,   MOV, диск −45°, без наклона
      наклон тела вверх-наружу
   [1c NTC-1] [2a NTC-2]              [2c MOV-1] [3a MOV-2]
   1b  L от C14 (обход по плоскости     2b  L к БП (подъём по центру
       стенки)                              лицевой грани из канала)
   1a  резерв, рычаг закрыт             3b  N к БП (подъём справа из канала)
                                        3c  N от C14 (вход над якорем)
```
Узлы: клемма 1 = L до NTC {1b, 1c}; клемма 2 = L после NTC {2a, 2b, 2c}; клемма 3 = N {3a, 3b, 3c}. NTC последовательно в фазе; MOV между фазой после NTC и нулём.

## Трассы
- **От C14:** клеммы «мама» на штырях L/N/PE с персональной разгрузкой ([T-001](../../techniques/T-001-crimp-female-6.3.md)); пучок по правой стороне вдоль банки фильтра; пролёт C14→якорь 35–40 мм без опор; клипса №1 — точка разгрузки пучка ([T-004](../../techniques/T-004-cable-clips.md)); хвосты: N → 3c (5–10 мм), L → обход по плоскости стенки, PE → вниз по правой кромке.
- **К БП:** три одиночных провода: коричневый (L) → 2b, синий (N) → 3b, жёлто-зелёный PE транзитом; на полу трилистник, клипса №2; PE длиннее L/N на 2–3 см ([T-003](../../techniques/T-003-slack-rules.md)); у БП НШВИ ([T-002](../../techniques/T-002-crimp-nshvi.md)).
- L/N прокладывается по правой стороне отсека, максимально удалённо от сигнальных цепей.
