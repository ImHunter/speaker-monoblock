# Проверки силового ввода

Источник: v8.0 §4.4.9, §7 (шаги 1–2).

| ID | Тип | Проверка | Критерий |
|---|---|---|---|
| TEST-PWR-01 | электрическая | PE: лепесток C14 ↔ FG БП | сплошная цепь |
| TEST-PWR-02 | электрическая | L: штырь LOAD L ↔ L БП; N: штырь LOAD N ↔ N БП; изоляция | цепь есть; изоляция >1 МОм |
| TEST-PWR-03 | механическая | Рывок трасс; пальцевый тест NTC/MOV; зазоры по T-006 | неподвижны, не качаются |
| TEST-PWR-04 | вибрационная | Бас-тест 40–80 Гц | нет дребезга |
| TEST-PWR-05 | тепловая | Прогон 30–60 мин | зажимы ≤60–70 °C, ASA-угол ≤40–45 °C |
| TEST-PWR-06 | повторная | Подтяжка саморезов через 24–48 ч | выполнено |
| TEST-PWR-07 | прозвонка до включения | L–N на C14: выключатель OFF → ∞; ON → ≈5–8 Ом (OQ-011); КЗ нет | по условию |
