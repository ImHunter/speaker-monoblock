# Программирование JAB4

Источник: v8.0 §8.1, §8.3, §8.4. Нужно: программатор ICP3/USBi, ПК с Windows, SigmaStudio 4.6/4.7.

## Подключение
1. DIP-переключатель №1 на ICP3 в положение **I2C** (обычно ON).
2. Обесточить JAB4 (выключатель C14 OFF); соединить ICP3 и разъём PROGRAM на JAB4 6-пиновым шлейфом; ICP3 — в USB ПК.
3. Включить питание колонки (C14 ON): плата должна быть запитана от своего БП, программатор её не питает.

## Связь в SigmaStudio
1. File → New Project.
2. Вкладка Hardware Configuration: блоки **USBi**, **ADAU1701**, **E2Prom**.
3. Шина I2C: от нижнего синего контакта USBi к верхнему синему контакту ADAU1701, затем от той же линии — к верхнему синему контакту E2Prom.
4. Верхняя полоса USBi зелёная — связь есть. Красная — драйверы USBi, питание JAB4, переключатель I2C/SPI.

## Запись в EEPROM
1. Link-Compile-Download (синяя стрелка).
2. Hardware Configuration → ПКМ на ADAU1701 → **Write Latest Compilation to E2Prom**.
3. Протокол по умолчанию (I2C) — OK; дождаться зелёной шкалы.

## Проверка автономности
C14 OFF → отсоединить шлейф → C14 ON. Колонка стартует, сопрягается по Bluetooth, громкость работает, каналы разделены правильно.

## Опциональная внешняя антенна SMA
Если Bluetooth слабый: отверстие ∅6.5 в задней панели (X=175, Y=100), разъём SMA снаружи с изолирующей шайбой изнутри (не касаться экрана), пигтейл U.FL→SMA к разъёму ANT/U.FL на JAB4, штыревая антенна 2.4 ГГц.
