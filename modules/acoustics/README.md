# Модуль acoustics — расчёт ЗЯ и демпфирование

Источник: v8.0 §1.4 (акустика), §4.12. ADR: [ADR-002](../../docs/decisions/ADR-002-closed-box.md). Параметры: [`params/acoustics.yaml`](../../params/acoustics.yaml).

## Расчёт
- Геометрия 6.87 л → эффективный 5.9 л (вычеты: бруски 0.30, корзина и магнит 0.50, колодки и провода 0.15 л).
- Qtc ≈ 1.05, Fc ≈ 95 Гц (OQ-006: расчёт даёт Qtc ≈ 1.10).
- −3 дБ: 70–75 Гц без DSP, 60–65 Гц с DSP.

## Демпфирующие маты (съёмные)
Синтепон 100–150 г/м² (слой 10–20 мм) в оболочке из спанбонда 60–80 г/м², простёганной по периметру и поперечными строчками. Крепление: мягкая часть велкро (петли) по периметру мата; жёсткая часть (крючки 20×20 мм) точечно на эпоксидный клей по углам. Устанавливаются на все поверхности акустического отсека, кроме передней панели.

Размеры и количество точек — [`mats.yaml`](mats.yaml).

## Укладка проводов
Жгуты от колодок к динамикам идут по дну акустического отсека, фиксируются стяжками с самоклеящимися площадками **до** установки нижнего мата; нижний мат закрывает провода.

## Изготовление
1. Вырезать синтепон по размеру поверхности минус 5 мм по периметру.
2. Обернуть тканью с припуском 20 мм, прошить по краю и сделать 2–3 поперечные строчки.
3. Пришить петли велкро по периметру с шагом по точкам на корпусе.
