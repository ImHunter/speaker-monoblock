# T-004: Монтаж кабельных клипс

Компонент: `CMP-cable-clip-7mm`.

- Только на саморез 3.5–4 мм через фольгу.
- Липучка и скотч запрещены.
- Зажим только на прямых участках; на дугах изгиба запрещён.
- Отступ от дуг изгиба не менее 15–20 мм.
- Номинал клипсы = измеренный пакет проводов + 0…0.7 мм (трилистник 3×ПВ3 0.75 мм² ≈ 5.6 мм → клипса 7 мм; при необходимости лайнер 1 мм из силикона).

Клипсы узла: CLIP-1 (правая стенка, y≈15–20 мм), CLIP-2 (пол, середина прямого участка) — `params/power.yaml → clips`.
